# Проект "Маски для банков"

## Описание:

Проект "Маски для банков" - это приложение для создания масок счетов или карт

## Установка:

1. Клонируйте репозиторий:
```
[https://github.com/LeshkaKlein/test-Poetry.git](https://github.com/irawildrun/PythonProject4)
```

2. Установите зависимости:
```
poetry install
```

## Использование:

1. Запустите программу:
```
python main.py
```
2. Следуйте инструкции
